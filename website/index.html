🚀 AWS Static Website

Hosted on Amazon S3 | Delivered via CloudFront | Managed with Route 53

Project Overview

This static website is hosted on Amazon S3 and distributed globally using Amazon CloudFront with HTTPS enabled through AWS Certificate Manager.

Services Used

  • Amazon S3 – Static file hosting
  • Amazon CloudFront – CDN & HTTPS
  • Amazon Route 53 – DNS management
  • AWS Certificate Manager – SSL/TLS

Key Features

  • ✔ Secure HTTPS access
  • ✔ Low latency with global CDN
  • ✔ Highly available & scalable
  • ✔ Cost-effective architecture
